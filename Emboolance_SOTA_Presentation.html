05 | Memory Engineering

Why Zero-STL? Deterministic Memory & Real-Time Safety

Custom memory-managed data structures replacing standard library containers

Prohibited Containers vs Custom Zero-STL

  • ◆ std::vector Prohibited: Replaced by Core::CustomVector<T> with explicit move semantics, custom destructor, and amortized doubling.
  • ◆ std::priority_queue Prohibited: Replaced by Core::CustomMinHeap<T> ensuring predictable binary heap operations with zero hidden reallocations.
  • ◆ std::map / std::set Prohibited: Replaced by contiguous indexed arrays and custom Disjoint Set Union (DSU) structures.
  • ◆ std::queue Prohibited: Replaced by indexed head-pointer structures over contiguous CustomVector buffers.

Real-Time Advantages

  • ◆ Zero Hidden Allocator Locks: Eliminates multi-threaded heap contention during high-casualty dispatch surges.
  • ◆ Guaranteed Cache Locality: Flat memory layouts maximize sequential L1/L2 cache prefetching.
  • ◆ Predictable Footprint: Total memory for 1,000 nodes and 3,990 edges occupies only ~132 KB of RAM.
  • ◆ Sub-Millisecond Verification: Dijkstra computes path across 1,000 nodes in 0.0018 ms (< 50ms requirement).
